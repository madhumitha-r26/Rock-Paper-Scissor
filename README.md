# Rock-Paper-Scissor

This is a simple project developed using python programming language in which the user can play rock, paper, scissor game with the system.

Here the user can enter either of the three choices:
1. R for Rock 
2. P for Paper
3. S for Scissor

whereas,
- R beats S
- P beats R
- S beats P

The user can play the game by giving the one of the inputs. The system generates a random choice among the input. If the user wins, the score will be printed. If the user wins the game with a message "YOU WON!" otherwise "BETTER LUCK NEXT TIME!" message will be printed. If the user input and the system's choice are same, a message "GAME IS IN TIE!" is displayed to the user.
